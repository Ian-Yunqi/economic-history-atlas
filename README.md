# 浪潮与转折：世界经济史阅读手册

40个世界经济事件的背景、事件与影响，以及实际人均GDP、全球商品贸易和美国通胀图表的解读与来源核查。

- 单页静态网站，无外部运行依赖。
- 支持事件搜索、原稿对照、交互式图表和CSV导出。
- 各事件与图表的公开参考来源列于网页内。
- 历史事件截至2023年；GDP截至2022年，商品贸易截至2014年，美国CPI截至2024年。

本仓库使用 GitHub Pages 从 main 分支根目录发布。

## 直接点选编辑

1. 点击网页右上角“编辑文字”。
2. 点击虚线框内的标题、日期、事件解释或图表解读，直接修改。
3. 点击“下载修改版 HTML”，保存可独立打开和再次编辑的文件。

文字草稿会尝试暂存在当前浏览器。修改不会自动覆盖公开网站；下载的版本需要重新上传发布，才会更新分享网址。图表曲线、原始数据、来源链接与原稿对照保持只读。
